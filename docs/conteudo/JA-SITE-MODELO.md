## História — JA integral

### Abertura

> 歴史の前に、ひとつの文明が世界の形をめぐって戦った。
>
> 北欧のサガやギリシアの叙事詩のように、『向こう側』はキリスト教神話への深い潜行である。創造と贖罪の物語を語り、天上の戦は永遠の平和へと至る。
>
> 『向こう側』は、次元の狭間 — 現にあるものと約束されたものとの折り目 — を争う原人類の内戦を描く。ひとつの血統から二つの秩序が生まれる。狭間を閉じたままにする者と、引き裂こうとする者。

### 三つのシリーズ

**01 Saga** — 全五シーズン ／ 全五巻 ／ 漫画本編

> 『Saga』は向こう側から語られる贖罪の物語。剣と知略で戦われる過酷な戦であり、軍団が敵に降り、将は力のみならず戦略を振るう。全五シーズンにわたり、天軍と客人の永遠の相克を、人の運命を天秤に載せながら描く。

**02 Genesis** — 前史 ／ 劇場長編・書籍

> 『Genesis』は起源である。『指輪物語』に対する『シルマリルの物語』のように、『Saga』の前史として、戦の始まる前に何が起きたかを神話として語り直す。劇場長編として企画され、第二シーズンと第三シーズンの間に公開予定。深みと文脈、そして古き歴史を届ける。

**03 Unveiled** — 終章 ／ 劇場長編・書籍

> 『Unveiled』は最後の光。第五シーズンの終幕のあと、多くの者が愛した人物たちの行方を思うだろう。『Unveiled』はシリーズ後の劇場作品として、決着と謎と結びをもたらす——『向こう側』の旅の最終幕である。

### 汚された井戸

> 叛乱の後、汚す者たちは高き天の生ける水がもはや自分たちを受け入れぬことを知った。かつて癒したものが、いまは焼いた。彼らは抗って聖なる水を奪い、深淵へ持ち込んだ。そこで蛇の王の眼差しのもと、盗まれた恵みは禁じられた錬成によって歪められ、汚された井戸が生じた。
>
> 井戸は回復を与えるが、代価を取る。訪れるたびに魂が蝕まれる。形は捩れ、本質は朽ち、見分けもつかぬまでに汚された者は責め苦の者となり、人の世に放たれて混乱と恐れを撒く。
>
> 井戸が闇の力を授けるとはいえ、元の形を保つ者にはなお畏敬が向けられる。堕ちた者のうちで汚れずにいることは稀であり、それは恐るべき強さの証である。深淵において腐敗は力であり、耐えることは栄光なのだ。

### 人のための戦

> 星の時代、天の議会が召集され、全能者はその設計を明かした。新しい世界を——新たな種が興る、住まうべき星を——生じさせること。彼らは人と呼ばれる。永遠者と異なり、群として生まれるのではなく地に増え広がり、塵より形づくられながら、形づくった者の像を帯びる。時が満ちれば、天の交わりに迎えられる。
>
> だがそこに、天を揺らし永遠を瀬戸際に立たせる、より大きな神秘が続いた。この世において永遠者は人に仕える。そして来たるべき世において、人は彼らを裁く者となる。
>
> その瞬間、ヘレルの心は石となった。彼は勅を拒んだ。誇りとして始まったものは公然の叛意となり、その心は玉座そのものを欲した。もはや覆いもなく、彼の叛乱は至高者に向かって噴き上がり、永遠者の内戦に火を点けた。彼の目に、人を屈服させることは単なる戦略ではなく自己保存である。密かに彼は楽園を築く——神なき理想郷、自我が玉座に据えられ、設計者が忘れられた地を。
>
> そして人の子らはおおむね永遠の戦に目を閉ざしていても、その戦は少しも虚ではない。それは彼らを取り巻き、王国を形づくり、心を掻き立て、歴史の流れを移す。

Fala do Helel: 「この劣った者どもに仕えよと? その者らに裁かれよと? 不条理だ。」

### キリスト教神話

> 『向こう側』はキリスト教神話に根を持つ作品である。聖書の物語に忠実でありながら、聖書的シナジズムの手法を用いる——聖典を尊びつつ、歴史・伝統・神学的想像力と対話し、聖書が示す輪郭のうちに収まる世界を築く方法である。作者は聖書的正確さを重んじるが、『向こう側』は最終的に虚構の作品である。聖典の出来事はそのままに、行間で起こることは幻想によって形づくられる。天使は帷の背後で衝突し、力は見えぬまま動き、選択は界を越えて波を打つ。
>
> また言い添えねばならない。聖書解釈には多くの学派がある。ひとつの道を選ぶことは、必然的に他を置いていくことである。『向こう側』はあらゆる教義を満たすふりをしない。むしろ、最も偉大な物語——贖罪の物語——を語ろうとする。

### 注意 (Aviso)

> 『向こう側』はダークファンタジーの想定譜である——聖書の主題を、見えぬ戦と永遠の帰結の神話世界に織り込んだ再構想。激しい暴力、陰鬱な主題、感情の重い語りを含む成人向け内容を含む。成人読者に推奨。

## Personagens — JA integral

Abertura: 登場人物は数多い。本ページでは、九つの階級を順に紹介する。

### 第一階級 — ガブリエル — `HERALD // COHORT`

> コホートは天軍の基盤をなす働き手である。自ら望む心をもって形づくられ、務めに縛られ、揺るぎない決意で高き天の意志を遂行する。星の時代、奉仕へと傾いた永遠者たちがこの階級に任じられた。一対の翼を持つコホートは天軍の背骨であり、兵であり、使者であり、必要とされるものすべてである。アルコンの力もプリンシパリティの神秘も持たぬが、その忠信があらゆる戦の帰趨を定める。
>
> その中でガブリエルの名は高い。至高者の伝令たる彼が武器を持つ姿はほとんど見られない。並ぶ者なき戦士でありながら、彼は戦を避ける。戦を恐れるのではなく、己の手が為しうることを恐れて。ゆえに彼は武器を持たず、鋼ではなく言葉の重みを携えて戦場へ歩み入る。その声は戦を黙らせ、王を悔いへと導いた。彼のうちにコホートの召命が余すところなく現れている。支配するためではなく、力と目的と平和をもって仕えるために。

### 第一階級 — アムネト — `DEFILED // COHORT`

> アムネトは本シリーズで最も視覚的に際立つ人物の一人であり、その姿は〈汚された井戸〉が時とともに何をもたらすかをそのまま示している。肌は黒く鱗に覆われた革のようであり、顔立ちは厚く重く、ナイル河口の古き鰐を思わせる。
>
> 最も特徴的なのは右腕である。かつて右腕であったものは、融合した複数の肢の醜怪な塊となり、それぞれに手と指を備え、蛇の結び目のように絡み合ってうねる。個々の手は意志に反して蠢く。その塊自体が生を持っているのだ。

### 第二階級 — ミカエル — `THE WARMONGER // ARCHON`

> アルコンは天軍において最強の戦士たちである。前なる時代、力に惹かれた永遠者たちであり、力は惜しみなく与えられた。その剛勇と不屈に並ぶ階級はなく、戦の趨勢を決する存在となる。裂界の武器を託されるのは彼らのみ——天軍の鍛冶頭ゾルファエルの傑作であり、炎に鍛えられ、設計者みずからの手で聖別されている。これらの武器は空間の織り目そのものを裂き、界と界、戦場、そして帷（ヴェイル）さえも越える門を開く。アルコンは二対の翼を持つ。ひとつは広く威を放ち、もうひとつは小さく迅い——猛烈な突撃と完璧な空中機動のために造られた翼である。
>
> その中で、戦を招く者ミカエルより高く立つ者はいない。屈することなく、敗れることなく。その存在のみで天の敵の心に恐れを打ち込む。彼の槍ウェリタスは、戦の始まりにゾルファエルの鍛冶場から最初に抜かれた武器である。ミカエル以外の手がそれを握ったことはない。

### 第二階級 — サティス — `FALLEN BLADE // ARCHON`

> サティスは目を引く。抑制された優雅さをまとう永遠者であり、井戸による進行性の損壊にあってもその佇まいは崩れない。髪は白く輝き、その静かな光沢は彼女の身を置く環境と相容れないように見える。色あせた印章を施した黒い鎧が身を包み、彫りは時と戦によってほとんど摩耗している。背には〈オニキスの破片〉を負い、砕けた先端はかえってそれを危険なものにしている。
>
> 腕と脚には異形の刻印が這い、その形は自然な比を僅かに超えて引き伸ばされている。井戸の腐蝕が、ゆっくりと彼女の上に広がっているのだ。

### 第三階級 — セレステ — `WEAVER // PRINCIPALITY`

> プリンシパリティは知の君侯であり、前なる時代に叡智へと傾いた永遠者たちである。内戦のはるか以前より、彼らは文の設計者、天の秩序の管理者、そして天上の力を織る者であった。秘術の練達において天軍に並ぶ者はない。その魔術は精緻で厳格であり、多くは唱えるにつれ空中を巡る輝く文字として記される——言葉のひとつひとつが鍵、記号のひとつひとつが門である。
>
> セレステはプリンシパリティであることの意味を体現している。軍議に常に列し、その声は将にも賢者にも重く響く。しかし戦が始まれば、彼女は後ろに控えない。手を挙げれば天が応え、同胞のために戦場そのものを塗り替える奇蹟を解き放つ。

### 第四階級 — アリエル — `VIALBEARER // VIRTUE`

> ヴァーチューは、プリンシパリティのような秘術の知ではなく、生来の発露から力を得る恐るべき存在である。その臨在は戦場のみならず地域全体を形づくり、かつて混乱のあった場所に力と回復と明澄をもたらす。多くは見えぬまま界を渡り、癒しと救いが人へ注がれる器となる。頭を戴く気高い一対の角——第二階梯の権威の象徴——を帯び、翼は一対。公然の戦に現れることは少ないが、その影響は否みがたい。戦の前、彼らは美を慕った永遠者たちであった。芸術家、夢見る者、光を歌う者として、かつて宇宙を驚異で満たした。
>
> その中でアリエルは希望の灯である。彼女の歩むところに癒しが続く。高き天の生ける水を納めた聖なる小瓶を携え、一滴で倒れた戦士を立ち上がらせる。アリエルは忍耐深く落ち着いていながら、決して遠くはない——兄テッセリオンとの絆は断ち切れない。

### 第五階級 — テッセリオン — `STORMBEARER // POWER`

> パワー——守護者（カストディアン）とも呼ばれる——は、古き者や永遠者の同胞とは異なる。古き者が長老の徴を帯び、永遠者がひと息で召し出されたのに対し、パワーは後に来た。星の時代の大いなる繁茂のうちに生まれたのである。宇宙が広がり、創造の構造が果てなく大きくなるにつれ、永遠者たちは助けを求めて叫んだ。応えとして守護者が鍛えられた。至高者の意志によって形づくられ、年長の同胞の手が作業を導いた巨大な存在である。光と鋼の巨人のごとき偉容をもって、彼らは遠き天の守り手となり、構造と調和と均衡を保つ。天軍で最も若いが、その存在感に並ぶものはない。守護者はそれぞれ唯一の姿を持ち、翼を持つ者もあれば持たぬ者もある。
>
> その中に嵐を負う者テッセリオンが立つ。鎧をまとった山のごとくそびえ、城塞ほどの刃を振るう。獅子の兜は避難所の象徴となった。口から出る言葉は少ないが、妹アリエルとの絆は断ち難い。

### 第六階級 — カルズール — `斥候 // DOMINAR — 客人側`

> ドミナーは第二階梯の頭に立ち、二対の翼と頭を戴く気高い角を帯びる。前なる時代に力と知の双方へ傾いた永遠者たちであり、その結合によって別種のものとなった。アルコンほど強くはなく、プリンシパリティほど秘術に長けてもいないが、いずれにも秀でている。体と心、刃と呪の均衡は、他者が予期しえぬ形で彼らを危険な存在にする。戦略家であり、指揮する者として、上と下の天軍を繋ぐ架け橋となり、天使が踏むのを恐れる場所へ突撃を率いる。
>
> かつてその中にカルズールが立っていた。野心に誘われ、彼は汚す者たちに与し、昇ることの約束のために光を捨てた。直近の敗北はミカエルの手によるものであり、それは敗北のみならず屈辱であった。角は裂け、肌は黒ずみ、名は汚された。階級を剥がれ、バビロンの君に捨てられ、ただの斥候に降格された。それでもカルズールは残る——狡猾に、忍耐深く、油断なく。なお戦術家であり、まだ黙らされていない影である。

### 第七階級 — オルスラクス — `堕ちた眼 // OPHANIM — 客人側`

> オファニムは第一階梯に属する。恐るべく輝かしい美をもつ存在であり、創造の最も古い金属から鍛えられた噛み合う輪で形づくられている。その骨組みは、瞬きも休みもしない無数の眼で燃えている。セラフィムが全能者を見つめるのに対し、オファニムはその視を外へ、宇宙の最果てへと向ける。他の者のように語らず、オファニクスで共鳴する——発声されず、放たれる言語である。輪がひと巡りするたび、圧縮された真理の波が界を渡る。その語りは振動であり、その歌は啓示である。解し得る者は少なく、応え得る者はさらに少ない。
>
> それでも、その中の一者が堕ちた。オルスラクスはかつて一致の柱であり、天を結ぶ油断なき眼であった。いまは蛇の王に仕え、客人の目が届かぬ領域へ遣わされる。その臨在は汚された者たちに視力を与える——だが代価を伴う。オファニムが戦場に入れば、天は応えねばならない。賭けは上がり、帷は焼ける。オルスラクスはもはや単なる見張りではない。彼は警告である。

### 第八階級 — ヘレル — `客人の王 // CHERUB`

> ケルビムは畏怖と驚異の存在であり、美と神秘において計り知れない。全能者の意志の最初の息のうちに形づくられ、永遠者より先にあり、力においてこれを超える。その真の姿はこの世のものではない。翼の上に翼を重ね、炎と風の体をもち、面は火のように移り変わる。それでも天軍のうちでは、しばしば大いなる獣として現れる——荘厳に、兆しのごとく広がりを翔けて。年下の同族との交わりを望み、彼らは「面（ヴィサージュ）」を取った。必要ではなく、情愛によって選ばれた人型の姿である。
>
> その中にヘレルが立っていた。輝かしく力強く、栄光をまとった君であり、奥義を託された者であった。だが時とともに、光は内へ向いた。なぜ栄光は玉座へ帰るのか、なぜ力は分かたれるのか、なぜ塵が全能者の像を帯びるのか——彼は問うた。偽りを語り、背を向け、叛乱の火を点けた最初の者となった。永遠者の三分の一が彼に従った。ゆえに彼は投げ落とされ、翼は断たれた。かつて古き龍であった者は、いま影のうちを這う。それでもその美は残り、汚された井戸に損なわれてはいない。彼は戦の設計者。客人の王である。

### 第九階級 — セラフィム — `燃える者たち // 第一階梯`

> セラフィムは古き者たちの最初であり、その種の最年長、第一階梯の頭である。天軍のうちで彼らのみが「解する」賜物をもって形づくられた——単に知るのではなく、深く、余すところなく理解する力である。その思いは設計者自身の息とともに動く。ゆえに彼らは玉座の間を一度も離れたことがない。命でも鎖でもなく、選びによって——魅せられて——とどまっている。玉座に座す方の栄光をひとたび見た者は、目を離すことができないのだ。
>
> その礼拝は終わらない。歌えと命じられたからではなく、見ることをやめられないからである。声は深く重なり合い、炎の轟きのように高き天に響く。六つの翼、無数の眼、そして彼ら以外には耐えられぬ火を帯びる。行くところで彼らは燃える。その臨在は圧倒的であり、その洞察は測り難い。これが燃える者たち——最初に見た者であり、最後まで目を離さぬ者である。
